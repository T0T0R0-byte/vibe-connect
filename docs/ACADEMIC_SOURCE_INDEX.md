# Academic Source Material

This repository's project documentation was reconstructed from the group's archived Commercial Computing material across the two semesters.

## Semester 1 material

The archived material includes the original VibeConnect proposal, stakeholder/problem analysis, requirements, user personas, research findings, system proposal, early architecture, and initial design work.

## Semester 2 material

The archived material includes the sprint backlog, Sprint 1 report, Sprint 2 report and presentation, Sprint 2 test cases, Sprint 3 report and backlog, Sprint 3 role-based product backlog, Sprint 4 report and presentation, final product backlog, and project/source links.

## Key source documents used

| Material | Purpose |
|---|---|
| VibeConnect Semester 1 proposal | Problem definition, research, requirements and initial solution |
| Sprint 1 report | Initial implementation and team workflow |
| Sprint 2 report | Payments, admin controls, refunds, bulk booking and consent |
| Sprint 2 test cases | Functional test coverage for Participant, Vendor and Admin roles |
| Sprint 3 report | Authentication, Stripe, refund refinement, reporting and security work |
| Sprint 3 backlog / product backlog | Backlog refinement and Agile priorities |
| Sprint 4 report | Final product charter, completed features, testing, security and final hosted system |
| Sprint 4 presentation | Final product demonstration and presentation material |

## Primary project archive

The original semester material is retained in the ChatGPT Library archive as `cc.zip` and related Commercial Computing files.

The repository contains the important project information as Markdown so visitors can read the project history directly from GitHub without needing proprietary office software.

Original DOCX, PPTX, XLSX and PDF files were not copied into GitHub because the connected GitHub file API available for this workflow only supports UTF-8 text file creation. The source archive remains available in the Library.
